# 余烬远征 / Emberbound

基于《游戏设计.md》的中文五人自动对战爬塔可玩原型。v0.4.0：浅色遗迹美术、紧凑底部指挥栏、完整英雄头像与绘制角色；保留指挥权、遗物构筑和本地 Three.js 战场。纯静态网页，部署无需 npm 安装或构建，不依赖运行时 CDN。

## 运行

使用任意静态 HTTP 服务将 `dist/` 作为根目录。入口为 `dist/index.html`。不要用 `file://` 打开，因为浏览器 ES modules 需要 HTTP。

## 玩法

1. 默认阵容可直接开始战斗。前两位为前排，后三位为后排。
2. 点击敌方单位设置全队实时普攻集火；战斗中点击己方单位选为护佑目标，战前点击英雄卡打开详情。
3. 通过「条件 → 动作 → 目标」规则配置普攻、大招、保护。相同动作按规则顺序选择首条命中项；条件未满足时保留大招。
4. 赢得金币、经验、余烬和装备。工坊可打造、购买、装备；英雄详情可训练、调整专精与职业。
5. 每三层为首领，15 层结束。失败不扣资源，可重新调整免费挑战。
6. 页面自动保存进度至当前浏览器 localStorage。重开远征会弹出二次确认。后台标签页自动暂停，空格暂停/继续，Esc 关闭面板。

## v0.3：见招拆招

- **共享 3 点指挥权**，每场重新补满，1 秒模拟时间公共冷却。指令在暂停时也可使用，无效目标不扣次数。
  - **断法**：点击危险读条，打断并眩晕施法者。敌人读条 3 秒，目标从预告到结算保持一致；英雄眩晕也能打断。
  - **护佑**：选择存活队友，获得最大生命 40% 的护盾与 5 秒减伤；盾值不会在 5 秒后自动消失。
  - **突击**：选择存活敌人，5 秒全队攻速增益与临时集火，并穿透前排守卫的后排掩护；结束恢复原战术。
- 首次教学读条自动暂停一次；之后每场首次读条自动降至 1×。可用「继续」或空格恢复，随时手动暂停决策。战斗时保留底部五人生命栏和指令，二级功能收纳至远征菜单。
- **遗物三选一**：回响法典强化连续施法，荆棘圣印强化护盾反击，猎王战旗强化突击击杀。每种上限 5 层；满层选项不可选择。胜利待选项先保存，选完才允许下一场，刷新不会重抽或重复领取。
- **遭遇轮换**：猎杀伏击威胁后排、破阵攻势保护后排并猛烈攻击前线、祭仪守军依靠关键治疗。战前侦察与实际预告目标对应，不必每层重复同一条指令。
- **可选精英**：敌方生命 +22%、攻击 +65%；金币 +60%、余烬额外 +3，装备至少稀有（首领至少史诗）。失败无资源惩罚，可改走常规路线；不会永久扣除队伍生命。
- **旧通关存档**可直接进行「终章演练」：保留英雄、装备、金币和进度，不消耗也不发放奖励。重置成长的新远征依然需要明确确认。
- 存档保存远征成长与待选遗物，不恢复半途战斗；刷新后本层可免费重试。遗物属于全队，和原有职业、装备、专精、条件战术共同生效。

## 内容与边界

- 11 位英雄、多个坦克/输出/支援专精，各自不同技能。
- 五人阵容、真实血量/护甲/暴击/闪避/法力/减伤/护盾/治疗/眩晕与光环模拟。
- 7 装备位置：头、胸、腿、鞋、饰品 I、饰品 II、武器。
- 5 种装备品质，正常关卡普通/稀有，首领必掉史诗；9/15 层额外掉神器，完整远征共 2 件。
- 工匠/珠宝师打造，辩手商店折扣与开战护盾。
- 俱乐部单日杯赛使用相同引擎模拟 AI，明确不是真人联网 PVP；不影响主线资源。
- 数值是原型值，不宣称复刻 Dota 2 当前正式服。缺少完整宝石/附魔、根据对方阵型自动变阵、联网、瑞士轮/双败/联赛/声望/选秀等系统。
- 英雄图形为原创建模感几何插画，没有使用游戏原作贴图。

## 架构

- `dist/engine.js`：无 DOM 依赖的纯战斗与成长逻辑。带种子伪随机、0.1 秒固定步长、规则目标解析、战利品防重复结算与存档结构校验。
- `dist/app.js`：输入映射、浏览器持久化、视图切换、2D 降级战场呈现、DOM 面板及动画。引擎状态是唯一战斗权威。
- `dist/renderer.js`：只读 Three.js 显示适配器，原始低多边形角色、竞技场、镜头、射线点选、事件特效；不推进战斗或结算奖励。
- `dist/vendor/three/`：固定 Three.js 0.180.0（MIT），两个本地 ES 模块与原许可证。
- `dist/renderer.css` / `dist/ui-v2.css` / `dist/ui-v3.css`：3D 血条、战斗文字与新版游戏 UI。
- `dist/style.css`：响应式暗色奇幻界面与 reduced-motion 处理。
- `dist/index.html`：静态入口。
- `engine.test.mjs`：引擎自动测试。

## 校验

从项目目录运行：

```sh
node --check dist/app.js
node --check dist/engine.js
node --check dist/renderer.js
node integration.test.mjs
node renderer.test.mjs
node engine.test.mjs
node gameplay.test.mjs
```

自动测试包括：确定性、不同帧切分等价、首战技能循环、精确目标战术、条件/禁用规则、重复结算保护、失败重试、前三层默认阵容、换装与属性、打造与资源、商店折扣、训练成长、史诗与神器掉落、所有英雄专精无 NaN/卡死、合法及损坏存档。

v0.1–0.2 历史记录（非本版平衡结论）：完成过一轮 1–15 层数值冒烟测试：仅自动经验、将掉落穿给五人、用多余金币训练，全部通关，战斗用时约 17–29 秒，证明成长闭环可完成。此测试不代表全组合平衡。

## Vercel 部署

从 Vercel 导入本仓库，保持 Root Directory 为仓库根目录。仓库中的 `vercel.json` 已设置静态输出为 `dist`，无需构建和安装依赖。若手动配置，Framework Preset 选择 Other，Build Command 留空，Output Directory 填 `dist`。

## 3D 操作与兼容

- 拖动战场旋转镜头，滚轮缩放；「重置镜头」回到默认战术视角。短点击才选择单位，拖拽不会意外改写集火战术。
- 「3D 实景 / 2D 战术」可在同一场战斗内切换。高画质开启阴影；省电模式关闭阴影并限制像素比。
- 3D 要求 WebGL2；加载失败或上下文丢失自动回退 2D，仍用同一引擎和同一存档。上下文恢复后可手动切回 3D。
- 技能特效显示施法者光环，治疗/伤害根据实际引擎目标显示；不把技能描述误当作额外命中。视觉动作无独立随机战斗或延迟伤害判定。
- 暂停冻结动作/特效，镜头仍可操作。此版本保留 `emberbound-v1` 存档键与版本 1 的存档格式，旧存档缺失的遗物字段自动补全，既有成长不清空。
- 场景、头像和角色立绘由图像生成制作，图标采用 Phosphor（MIT，许可随包附带）。Three.js 场景中的角色为面向镜头的绘制精灵（2.5D），不是新制作的骨骼模型；2D 兼容模式复用同一美术与战斗数据。当前没有空间寻路/物理碰撞：前后排阵位由已有战术引擎控制。

### 浏览器发布验收

开局、点选敌人、拖动不误集火、暂停/倍速、结算一次、第二场重置；3D/2D 来回切换；镜头重置与窗口缩放；英雄/工坊/阵容面板与存档重载；移动端布局；禁用 WebGL/上下文丢失时继续 2D。此清单需实际浏览器验证，不能用 Node 测试替代画面验收。

`renderer.test.mjs` 用真实 Three.js 场景/相机数学与非 GPU 后端覆盖角色、事件、暂停、镜头、上下文恢复和资源清理；不声称验证 GPU 像素、材质或性能。
